# Live-Sync

# Description
A Desktop application helps to sync between two files in real-time. Means the changes made to the source file directly reflect on the destination file

# Features
- Sync files in real time between the local editor and the lab environment.
- Remove the need to write the code in a less powerful editior.
- Real-time update.
- Simple to use

  # Motivation
This project was built to solve a problem we frequently faced during our lab sessions. Even though modern editors like VS Code provide powerful features—such as intelligent code suggestions, variable name completion, syntax highlighting, indentation support, and error detection—we still ended up writing code in the default file editor on Ubuntu (the genome editor). Working in that environment was inefficient and frustrating, as everything had to be handled manually.

To address this issue, I created an application that enables seamless synchronisation between files, allowing us to write code comfortably in a fully featured editor while automatically reflecting changes in the lab environment. This significantly improves productivity and reduces the chances of manual errors. Building a desktop app that detects real-time file changes from a source file/folder and reflects them in a destination file.
